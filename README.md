## About

This module introduces the essential mindsets, concepts, and practical skills needed to become an AI-enabled data professional. You’ll explore what it means to work alongside AI, map AI tools to your own data workflows, and learn how large language models (LLMs) work so you can use them confidently and responsibly in your day-to-day work.

## Content

| Lesson | Est. Delivery Time | Skills |
| ------ |:------------------:| ------ |
| [Becoming AI-Enabled in Data](./microlesson-01/README.md) | ~20 min | AI mindset, workflow reflection, getting hands-on with GenAI |
| [Mapping AI to the Data Workflow](./microlesson-02/README.md) | ~20 min | Data use cases, identifying where AI fits, recognizing AI capabilities and limits |
| [LLM Fundamentals & Responsible AI Use](./microlesson-03/README.md) | ~20 min | Understanding LLMs, prompt engineering for data, responsible AI practices |
| **Total content**                                   | ~1 hour |                                     |
